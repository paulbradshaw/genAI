# Files for classification

This file contains files for testing AI tools' classification performance. 

* The `hospitalcrimsecsvs` folder contains CSVs of data from a number of FOI responses. The subfolder `crimeclassification_csvs` contains data on crime classification, and outputs from a test run. Accuracy was low, and discussed in [this blog post outlining a more rigorous methodology](https://onlinejournalismblog.com/2026/06/30/managing-a-mass-foi-project-heres-a-methodology-for-that/)
